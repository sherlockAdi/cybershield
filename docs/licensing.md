# Licensing and dependencies

No license for ServerGuard AI has been selected by its owner. No third-party security-project source code was copied into this repository. Do not assume a public redistribution grant for the application merely because development tooling is open source.

Before a commercial release, review the exact versions in `pnpm-lock.yaml`, transitive licenses, native binaries, PostgreSQL/Redis container distribution terms, and any agent signing or security integration dependencies. Produce a license notice bundle and SBOM. Wazuh, CrowdSec and Lynis are reference projects only at this stage; no integration or license compatibility is asserted.
